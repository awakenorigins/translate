# translate — Accurate translation preserving meaning, format, and context

> Translate text across any language pair while keeping code untouched, placeholders intact, and cultural rules right. Plurals, gender agreement, formatting — all handled correctly.

[![OpenClaw Skill](https://img.shields.io/badge/OpenClaw-Skill-blueviolet)](https://github.com/NachaFromMars)

## Overview
translate delivers formatting-aware, accurate translation. It never touches code blocks, HTML tags, markdown syntax, or technical placeholders. Applies language-specific rules: correct plurals per target language (not English patterns), gender agreement in Spanish/French/German.

## Features
**Never translates:** code blocks, HTML/markdown syntax, `{name}` `%s` `$1` placeholders, proper nouns, brand names, URLs, email addresses
**Format-safe:** JSON/XML structure preserved (values only), markdown structure intact
**Language-specific:** correct plurals, gender agreement, consistent terminology

## Usage / Quick Start
- *"Translate this to English"*
- *"Dịch sang tiếng Việt"*
- *"Translate the UI strings in this JSON to French"*
